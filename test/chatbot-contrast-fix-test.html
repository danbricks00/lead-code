🎨 Chatbot Contrast Fix

✅ Issue Fixed: User Message Visibility

Problem: User input bubbles had poor contrast in light mode (gradient background similar to system messages in dark mode)

Solution: Changed user messages to solid blue background with better contrast

❌ Before (Poor Contrast)

Hi! I'm here to help you get a quote for underfloor heating.
I need heating for 3 rooms
Great! How many areas would you like heated?
3 rooms please

Issues:
• Gradient background hard to read in light mode
• Similar to system colors in some themes
• Poor accessibility contrast

✅ After (Better Contrast)

Hi! I'm here to help you get a quote for underfloor heating.
I need heating for 3 rooms
Great! How many areas would you like heated?
3 rooms please

Improvements:
• Solid blue background (#007bff)
• High contrast white text
• Distinct from bot messages
• Works in all lighting conditions

🔧 Technical Changes Made

📝 CSS Update:

Old styling:

.user-message {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    color: white;
}

New styling:

.user-message {
    background: #007bff;
    color: white;
    box-shadow: 0 2px 8px rgba(0,123,255,0.3);
}

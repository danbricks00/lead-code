🔧 Google Docs Template Setup Test

This page helps you set up and test the Google Docs template integration.

📋 Step 1: Create Your Template

Create a Google Docs document with these placeholders:

{{QUOTE_NUMBER}}
{{DATE}}
{{VALID_UNTIL}}
{{CUSTOMER_NAME}}
{{CUSTOMER_EMAIL}}
{{CUSTOMER_PHONE}}
{{CUSTOMER_ADDRESS}}
{{TRADESMAN_NAME}}
{{TRADESMAN_EMAIL}}
{{TRADESMAN_PHONE}}
{{ITEM_BREAKDOWN}}
{{TOTAL_AMOUNT}}
{{ADDITIONAL_NOTES}}

Example template structure:

QUOTE

Quote Number: {{QUOTE_NUMBER}}
Date: {{DATE}}
Valid Until: {{VALID_UNTIL}}

CUSTOMER DETAILS
Name: {{CUSTOMER_NAME}}
Email: {{CUSTOMER_EMAIL}}
Phone: {{CUSTOMER_PHONE}}
Address: {{CUSTOMER_ADDRESS}}

TRADESMAN DETAILS
Company: {{TRADESMAN_NAME}}
Email: {{TRADESMAN_EMAIL}}
Phone: {{TRADESMAN_PHONE}}

QUOTE BREAKDOWN
{{ITEM_BREAKDOWN}}

TOTAL AMOUNT: ${{TOTAL_AMOUNT}}

ADDITIONAL NOTES
{{ADDITIONAL_NOTES}}

🔧 Step 2: Get Template ID

After creating your template:

  1. Open your Google Docs template
  2. Copy the ID from the URL: https://docs.google.com/document/d/[TEMPLATE_ID]/edit
  3. Add it to Vercel environment variables as GOOGLE_DOCS_TEMPLATE_ID

🔍 Quote Expiry Validation System

This document explains how the quote accept/decline validation works with expiry dates.

📋 Validation Flow

✅ Valid Quote (Within Expiry Date)

Scenario: Customer clicks accept/decline button for quote that hasn't expired

System Check: validUntilDate > currentDate

Result: Decision is processed and logged with NZT timestamp

⏰ Expired Quote

Scenario: Customer clicks accept/decline button after the "Valid Until" date

System Check: validUntilDate < currentDate

Result: Redirects to error page with message:

"This quote has expired and is no longer valid. Please contact us to request a new quote."

🚫 Already Decided Quote

Scenario: Customer tries to click accept/decline for second time

System Check: Decision column not empty

Result: Shows previous decision with NZT timestamp:

"This quote was already accepted on 05/01/2025, 02:30 pm NZT."

🔧 Technical Implementation

Column Detection

The system automatically finds the expiry date column by looking for headers containing:

  • valid until
  • expiry
  • expires

Security Features

  • ✅ HMAC Token Verification: Prevents link tampering
  • ✅ Quote Expiry Check: Validates against stored expiry date
  • ✅ One-Time Decision: Prevents multiple submissions
  • ✅ NZT Timestamps: All decisions logged in New Zealand time

Error Handling Priority

  1. Token Validation: Invalid/tampered links
  2. Quote Existence: Valid quote ID check
  3. Expiry Validation: Quote still valid check
  4. Decision History: Already decided check
  5. Processing: Record decision with timestamp

📱 User Experience

Expired Quote Page Features:

  • ⏰ Clear "Quote Expired" heading
  • 📝 Helpful explanation message
  • 📞 Contact information for new quote requests
  • 🏠 Return to homepage button

Success/Error Messaging:

  • ✅ Success: "Your acceptance has been recorded!"
  • ⏰ Expired: Clear expiry message with contact info
  • 🚫 Already Decided: Shows original decision time in DD/MM/YYYY format with NZT

System ensures quotes are only valid for their intended duration and provides clear guidance for customers when quotes expire.
